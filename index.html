CLI — same engine, in your terminal
For CI, pre-commit, or when you live in the terminal. Packs your repo with the same rules as the Studio.
npx mosaic-context pack ./my-app \
  --query "fix webhook retry" \
  --model claude --max-tokens 120k \
  --scrub --include-imports \
  --out ./context.xml
# then: cat context.xml | claude -p "help"

Is my code sent anywhere? Can I use private repos?
No. Public GitHub fetch uses the public API (your browser → github.com, no proxy). Private repos: use drag-and-drop (100% local). You can audit Network tab — 0 uploads. Enterprise: self-host one HTML file.

    
How accurate are token counts?
Heuristic tuned per model: Claude ~3.3 chars/token, GPT-4o ~4.0, Gemini ~4.1 for code. Within ~5-10% of real tokenizers. For exact counts, we recommend verifying with provider’s tokenizer on the final export before huge batches.

    
What makes the prompt “perfect”?
Ordered by relevance (smart select + dependency closure), file map first (helps models navigate), XML tags for Claude, fenced code for GPT, chunk hints if near limits, and scrubbed secrets so you don’t leak keys.
